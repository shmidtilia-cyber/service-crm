# Service CRM

WordPress CRM для сервисного центра.

## Цель проекта

Собрать CRM для управления ремонтами, клиентами, инженерами, складом деталей, зарплатами и уведомлениями.

## Структура

```text
service-crm/
├─ plugin/
│  └─ service-crm.php
├─ assets/
│  ├─ css/
│  │  └─ crm-style.css
│  └─ js/
│     └─ crm-script.js
├─ docs/
│  └─ acf-fields.md
└─ tasks.md
```

## Первый этап

- Базовый WordPress-плагин CRM
- Шорткод `[service_crm]`
- Карточки заказов
- Статусы ремонта
- Подготовка под ACF-поля
